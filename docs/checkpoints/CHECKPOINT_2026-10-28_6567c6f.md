## Décisions et risques

- Décisions ajoutées : D008 (nœud `hapanel`, `esp-idf`), D009 (tactile lu
  périodiquement).
- R1 fermé ; R6 réduit (seule l'interruption du tactile GPIO21 ne
  fonctionne pas) ; R2 (mémoire) et R5 (écart ESPHome / Home Assistant)
  ouverts ; dette T1 (lecture périodique du tactile).
- Invariants préservés : G1 (aucune attente dans les lambdas), G2 (broches
  déclarées une seule fois, dans `hardware.yaml`), G5 (version et SHA
  injectés), G9 (aucun secret dans Git), G10 (noms posés par D008), P1 (aucune
  action Home Assistant autorisée), P5 (la page s'affiche sans Home
  Assistant).

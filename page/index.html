Installer HAPanel

Panneau mural pour Home Assistant. Version installée par cette page : @VERSION@.

Ordinateur avec Google Chrome ou Microsoft Edge uniquement. L'installation passe par le port USB, que les autres navigateurs, les téléphones et les tablettes ne permettent pas d'utiliser.
  1. Branchez le module à l'ordinateur avec un câble USB de données.
  2. Cliquez sur Installer sous votre carte, puis choisissez le port du module.
  3. Suivez la fenêtre (en anglais), puis saisissez votre Wi-Fi.

Le guide pas à pas, avec les captures et le dépannage : guide d'installation.

ESP32-2432S024C

  • Écran 2,4 pouces, tactile capacitif
  • Une prise USB-C ; puce ESP32
Navigateur non compatible : ouvrez cette page dans Chrome ou Edge, sur un ordinateur. Installation impossible depuis cette adresse.

ESP32-2432S028

  • Écran 2,8 pouces, tactile résistif (appui franc)
  • Deux prises : USB-C et micro-USB ; puce ESP32
  • Une S028 avec une seule prise micro-USB n'est pas encore prise en charge
Navigateur non compatible : ouvrez cette page dans Chrome ou Edge, sur un ordinateur. Installation impossible depuis cette adresse.

Guition JC4827W543 en essai

  • Écran 4,3 pouces, tactile capacitif ; puce ESP32-S3
  • Pages en portrait au centre de l'écran, bande noire en bas ; pas de LED
Navigateur non compatible : ouvrez cette page dans Chrome ou Edge, sur un ordinateur. Installation impossible depuis cette adresse.

Le nom de la carte est imprimé au dos du module ou sur sa boîte. Le logiciel d'une autre carte s'installe aussi, mais l'écran reste noir ou le toucher ne répond pas.

Après l'installation : débranchez puis rebranchez le module avant de juger l'écran, puis ajoutez-le à Home Assistant (configuration). Les mises à jour suivantes passent par Home Assistant ou par l'écran du module, sans câble.
